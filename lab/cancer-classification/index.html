Rebuilding a cancer-classification experiment

How much information about a cancer label survives a change in the way mutations are represented? I tested eight pipelines that distinguish lung adenocarcinoma from melanoma: a single mutation, tumor-level counts and frequencies, and a wide sample matrix with and without dimensionality reduction. Five pipelines classified all 22 final test tumors correctly. That result needs two qualifications from the start: the cohort is small, and the wide matrix has an unresolved missing-data interpretation.

This article follows the evidence from representation to evaluation. Each experiment has its own setup, training record, class metrics, probability-based curves, confusion matrices, and cross-validation plots. The purpose is not to declare a winning cancer detector. It is to explain what each comparison tests, what was measured, and where the evidence stops.

Study questions and data

A mutation records a substitution and its local sequence context. Mutational processes can leave different distributions over these features. This is the biological motivation for the experiment, not a finding of the classifiers. The pmsignature model uses a compact probabilistic account of mutation features to infer signatures. Here the task is different: supervised prediction of the supplied cancer label. These runs neither reproduce signature extraction nor identify which signatures drive a decision. They do not evaluate treatment benefit.

From one mutation to a tumor representation

Let $t$ index a tumor and $r$ index one of its $n_t$ retained mutations. Write $b_{tr}$ for the upstream base, $s_{tr}$ for substitution type, and $c_{tr}$ for the downstream base. The base alphabet is A, C, G, T; substitution order is C→A, C→G, C→T, T→A, T→C, T→G. The indicator $\mathbf{1}\{E\}$ below means one if event $E$ is true and zero otherwise.

x_{tr}=[\mathrm{onehot}_4(b_{tr}),\mathrm{onehot}_6(s_{tr}),\mathrm{onehot}_4(c_{tr})]\in\{0,1\}^{14}

M1 uses that row directly. M2 sums each indicator over a tumor, keeping the three marginal distributions. M3 instead counts each complete upstream–substitution–downstream combination. The difference is not just width: marginal counts lose the association among the three features.

Evaluation protocol and how to read the figures

Seven experiments share a seeded, shuffled, stratified tumor split. The development set supplies five folds; the final set is reserved for one evaluation after refitting. M1 instead splits mutation rows. These are different questions, so M1 is not ranked against the tumor models.

In fold $k$, fitting uses the other four development folds. The scaler, applicable imputer and MDS model, and classifier are fitted only within that training scope. The remaining fold supplies validation predictions. Concatenating those predictions gives one out-of-fold (OOF) prediction per development identity, not an in-sample training score. Validation loss controls neural early stopping; the final test controls nothing about rank, transforms, hyperparameters, or stopping duration. This distinction matters for preprocessing leakage.

\hat p_i^{\mathrm{OOF}}=f_{-k(i)}(x_i),\qquad e_{\mathrm{final}}=\mathrm{round}\bigl(\mathrm{median}(e_1^*,\ldots,e_5^*)\bigr)

Here $k(i)$ is row $i$'s validation fold. The notation $f_{-k(i)}$ means that preprocessing and weight updates exclude that fold, not that every selection decision is independent of it: its labels select the best epoch $e_k^*$. Neural OOF predictions are therefore validation-selected, and can be optimistic relative to an untouched evaluation of the entire selection procedure. They are not nested-cross-validation estimates. A new neural model is then fitted on all development data for the fixed duration $e_{\mathrm{final}}$. OOF pooling and a mean over fold scores are different summaries; a pooled AUROC also compares scores from different fold models. Neither is a confidence interval.

Every model estimates $p_i=P(y_i=1\mid x_i)$, with melanoma positive. The preselected decision rule is $\hat y_i=\mathbf{1}\{p_i\geq0.5\}$. For melanoma, true positives (TP) are correctly predicted melanomas; false positives (FP) are lung tumors called melanoma. False negatives (FN) are melanomas called lung, and true negatives (TN) are correct lung predictions.

\mathrm{precision}=\frac{TP}{TP+FP},\quad\mathrm{recall}=\frac{TP}{TP+FN},\quad\mathrm{FPR}=\frac{FP}{FP+TN}

A ROC curve plots recall (true positive rate) against false positive rate as the threshold changes. AUROC summarizes that ranking curve; it is not another curve or a threshold-0.5 accuracy. A precision–recall (PR) curve exposes the precision cost of recovering more melanomas. Its no-skill reference is positive prevalence, which differs slightly between development and final test. Confusion matrices show one fixed decision rule, not the whole ranking. Each experiment below shows both pooled OOF and final curves, then fold variation and training history. All charts are visible without a selector; open any image for full size.

M1 · Can one mutation predict the tumor label?

Setup and run

M1 asks how informative a single mutation's local context is. The input is the 14-indicator vector defined above, standardized with training-only means and scales. Each mutation inherits its tumor's supplied label. No tumor identifier is an input. The neural model sees rows rather than a tumor histogram; it cannot directly aggregate that tumor's evidence.

Row identities are disjoint across partitions, but the same tumor can contribute rows to both. This is deliberately a single-mutation prediction task, not a test on unseen tumors. The development-selected final refit duration was 46 epochs; the individual fold stopping records are tabulated below.

M2 · Aggregate the marginal mutation counts

Setup and run

M2 changes the prediction unit to a tumor. It sums the indicators for all retained mutations, preserving how often each upstream base, substitution, and downstream base occurs. For indicator position $j$:

x_{tj}^{\mathrm{M2}}=\sum_{r=1}^{n_t}x_{trj},\qquad\sum_{j\in G}x_{tj}^{\mathrm{M2}}=n_t

$G$ is any one of the three indicator groups. Each group's total is the tumor's retained mutation count, so M2 retains both composition and burden. The 14 counts are standardized within each training scope and passed to the shared neural architecture. No imputation or MDS is used. The development-selected final refit duration was 149 epochs; the individual fold stopping records are tabulated below.

M3 · Preserve the joint sequence context

Setup and run

M3 counts complete contexts rather than separate marginals. A bin is indexed by upstream base $b$, substitution $s$, and downstream base $c$:

h_t(b,s,c)=\sum_{r=1}^{n_t}\mathbf{1}\{b_{tr}=b,\ s_{tr}=s,\ c_{tr}=c\},\qquad\sum_{b,s,c}h_t(b,s,c)=n_t

Flattening in upstream–substitution–downstream order yields 96 counts. Summing over the other axes recovers M2's marginals. Two tumors can therefore share M2 features yet differ in M3 if their feature associations differ. M3 uses the same tumor assignments, scaler rule, and neural settings as M2; its input layer is wider. The development-selected final refit duration was 95 epochs; the individual fold stopping records are tabulated below.

M4 · Normalize the marginal counts

Setup and run

M4 divides each M2 count by that same tumor's retained mutation count. It keeps the same 14 positions while removing their explicit burden scale:

x_{tj}^{\mathrm{M4}}=\frac{x_{tj}^{\mathrm{M2}}}{n_t},\qquad\sum_{j\in G}x_{tj}^{\mathrm{M4}}=1

These are frequencies within a tumor, not proportions computed over the cohort. There are three normalized groups, not one distribution across all 14 positions. Training-only standardization follows normalization. The tumor split and neural settings match M2. The development-selected final refit duration was 139 epochs; the individual fold stopping records are tabulated below.

M5 · Normalize the joint-context histogram

Setup and run

M5 combines M3's joint representation with M4's own-tumor denominator. Its 96 positions form one empirical context distribution:

f_t(b,s,c)=\frac{h_t(b,s,c)}{n_t},\qquad\sum_{b,s,c}f_t(b,s,c)=1

No denominator is added as a feature. The common tumor assignments, training-only scaler, and neural settings make M3 versus M5 a count–frequency comparison with the same context vocabulary. The shared missing-data model for S0–S2

The sample experiments start from a much wider matrix, not from the 14- or 96-bin mutation histogram. Every original feature is retained. Because most cells are NA, their treatment is central to the result, not incidental preprocessing. S0–S2 share each fitted imputer and scaler only when the exact training scope matches.

SymbolMeaningShape or domain

$\mu_j$Mean of observed training values for feature $j$One fixed offset per feature

Alternate a decomposition and a missing-only update

Fix observed training column means, center the observed entries, and initialize missing centered entries to zero. A rank-$m$ decomposition supplies coefficients and loadings. Then replace only missing entries from that reconstruction, restore observed entries exactly, and decompose the updated matrix again. A single SVD followed by one fill would not implement this procedure.

\hat x_{ij}=\mu_j+a_i^{\mathsf T}v_j x_{ij}^{(q+1)}=\begin{cases}x_{ij},&(i,j)\in\Omega\\ \mu_j+(a_i^{(q)})^{\mathsf T}v_j^{(q)},&(i,j)\in\Omega^{c}\end{cases}

The iteration index is $q$. For example, an offset of 2, row coefficient $(1,-1)$, and feature loading $(0.5,0.2)$ reconstruct a missing value as $2+1(0.5)-1(0.2)=2.3$. This is an illustration, not an observed sample. If the value were observed as zero, it would remain zero instead. Because observed values are restored, the completed matrix need not itself have rank $m$.

Select rank with entries, not classifier test labels

In each training scope, three seeded repeats hide 10% of eligible observed entries while retaining row and column support. Every candidate rank uses the same masks. Mean hidden-entry RMSE chooses the rank, with lower rank breaking a tie; the winner is refitted on the original observations. Neither validation tumors nor final-test tumors enter this rank comparison. Entry reconstruction and classifier validation answer different questions.

Transform a new tumor without refitting the basis

For a held-out tumor, only its own observed entries fit row coefficients against the frozen training offsets and loadings. If $O_i$ denotes its usable observed feature positions:

a_i^*=\mathrm{arg\,min}_a\sum_{j\in O_i}(x_{ij}-\mu_j-v_j^{\mathsf T}a)^2

The minimum-norm least-squares solution uses a relative singular-value cutoff of $10^{-6}$. Missing values then use $\mu_j+v_j^{\mathsf T}a_i^*$; observed values remain unchanged. One held-out tumor cannot alter the basis or another held-out tumor's completion. Columns never observed in training use the global observed training mean and zero loadings; unsupported rows use zero coefficients. The final training scope has 73,033 unsupported columns. These explicit fallbacks preserve feature positions, not biological evidence. Negative completions are recorded, not clipped. Training-fitted standardization follows imputation.

S0 · A linear classifier on the full sample matrix

Setup and run

S0 uses every imputed, standardized sample feature. L2 logistic regression provides a linear log-odds baseline before introducing another neural network or a dimension reduction. Let $z_i$ be the completed, scaled training row and $\sigma$ the sigmoid:

p_i=\sigma(w^{\mathsf T}z_i+b),\quad\min_{w,b}\left[-\frac1n\sum_i\bigl(y_i\log p_i+(1-y_i)\log(1-p_i)\bigr)+\frac{\lVert w\rVert_2^2}{2Cn}\right]

$C=1$ fixes the penalty; the intercept $b$ is not penalized. The GPU implementation uses float64 L-BFGS for this same objective, checked against the CPU library solver. Each fold is fitted from fresh model state. There is no neural best-epoch rule. The final optimizer converged after 80 iterations, with gradient infinity norm approximately $9.0\times10^{-8}$, below the $10^{-7}$ tolerance. That is classifier convergence, not imputation convergence.

S2 · Ten-dimensional classical MDS before the network

Setup and run

S2 asks whether a low-dimensional account of the completed sample geometry is useful to the classifier. It uses the same full-width imputation and scaling, fits Euclidean classical multidimensional scaling (MDS) inside the training scope, and sends ten coordinates to the neural network. It does not select the ten dimensions from final test performance or replace MDS with PCA.

For $n$ training rows, let $D^{(2)}$ be their $n\times n$ squared-distance matrix. $H=I-\mathbf{1}\mathbf{1}^{\mathsf T}/n$ subtracts the mean. Double centering converts distances to a centered Gram matrix:

B=-\tfrac12 H D^{(2)}H=V\Lambda V^{\mathsf T},\qquad Z_{10}=V_{10}\Lambda_{10}^{1/2}

Columns of $V_{10}$ are the ten leading eigenvectors; the diagonal of $\Lambda_{10}$ contains their positive eigenvalues. $Z_{10}$ therefore has one row per training tumor and ten coordinates. Materially negative spectra or requests beyond supported positive rank are errors, not values to repair with an absolute sign.

A new tumor is projected against the frozen training reference, not embedded jointly with other held-out rows. If $d_j^2$ is its squared distance to training tumor $j$, $r_j$ is training row $j$'s mean squared distance, and $g$ is the training grand mean:

b_j=-\tfrac12(d_j^2-\overline{d^2}-r_j+g),\qquad z_{\mathrm{new}}=b^{\mathsf T}V_{10}\Lambda_{10}^{-1/2}

All reference points, distance means, eigenvectors, and eigenvalues remain fixed. Coordinates are not standardized a second time. Tests of training self-projection, serialization, and equivalence to Euclidean PCA scores up to sign or rotation check the implementation; they do not establish classification quality. The development-selected final refit duration was 45 epochs; the individual fold stopping records are tabulated below.

Interpretation

S2 performs poorly in both pooled OOF and final classification. It gets seven final lung tumors and six final melanomas right, missing eight melanomas. Ten coordinates retain about 62% of the positive spectrum, but not necessarily the information relevant to the label. Unsupervised geometry can emphasize other variation. Loss of useful dimensions is one hypothesis; coordinate scale and neural optimization are others. The runs do not separate these explanations. This is a result for this pipeline and configuration, not proof that dimensionality reduction or MDS is generally unsuitable.

What the comparisons do—and do not—establish

The clearest mutation comparison is counts versus frequencies on the same tumor split. Strong M4 and M5 results show that an explicit burden denominator is not required for discrimination here. Marginal versus joint counts changes one pooled OOF error; normalizing the joint counts changes one more. These small differences do not justify a stable ranking. We have one cohort, one final split, and no verified patient-level independence or external evaluation.

Tobacco- and ultraviolet-associated processes make a lung/melanoma distinction biologically plausible. The models did not estimate signature exposures, test causality, or rule out cohort and technical confounding. The useful finding is that the chosen mutation representations support prediction on this split, not that a specific process has been identified by the classifier.

The wide-matrix comparison is mixed: S0 succeeds on the final set, S1's high OOF discrimination does not transfer, and S2 is weak in both evaluations. Each inherits the same uncertain NA semantics and nonconverged imputation diagnostics. Even a perfectly implemented transform is only as meaningful as the input assumptions behind it.

Numerical audit and published evidence

The experiments run in an isolated Python 3.12 package with Keras 3 on PyTorch. The measured neural fits, sample imputation, MDS, and L2 logistic numerical path use an RTX 2080 Ti. Imputation, MDS, and logistic calculations use float64; neural inputs and weights use float32. File reading, mask generation, standard scaling, and serialization remain on CPU. Compatible sample training scopes share checksummed preprocessing; continuation times with cache reuse are not clean speed benchmarks.

GPU least squares needs particular care: the CUDA lstsq driver assumes full rank. A held-out row's observed subset need not satisfy that assumption. Its projection uses an SVD minimum-norm solution with the stated cutoff. The completed local suite passed 281 tests covering source audits, fit boundaries, numerical references, rank-deficient cases, GPU/CPU agreement, serialization, and end-to-end fixture runs. Those software checks do not validate biological provenance.
