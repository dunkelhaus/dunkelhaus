# Profile logo sources

The six badges use local SVG assets with text labels and light/dark surfaces. Order: Python, Go, AWS, JS, PyTorch, MQTT. Dark AWS wordmark and light Go logo colors are adjusted for readability; MQTT uses the profile magenta accent.

Python, Go, AWS, JavaScript, and PyTorch logo artwork: [Devicon](https://github.com/devicons/devicon), under its [MIT license](https://github.com/devicons/devicon/blob/master/LICENSE). Source paths: icons/python/python-original.svg, icons/go/go-original-wordmark.svg, icons/amazonwebservices/amazonwebservices-original-wordmark.svg, icons/javascript/javascript-original.svg, icons/pytorch/pytorch-original.svg.

MQTT logo artwork: [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/mqtt.svg), under [CC0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).

Brand names and logos belong to their respective owners. These badges identify tools used; they do not indicate endorsement. No runtime image service or JavaScript is used.

The README uses a small, right-aligned `pattern.svg` beside the introduction. It reuses the original cyan/magenta vector artwork from the former banner, with a transparent background for GitHub light and dark themes. Tool badges retain their theme-specific surfaces.
